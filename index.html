System & Code Troubleshooting Matrix

Step-by-step diagnostic solutions for Termux, Android ADB, and compilation errors.

Termux Error

Repository Mirror Connection Failed

When apt update fails due to dead mirrors or network timeouts.

Run: termux-change-repo
Select default mirror and re-run pkg update.
ADB Shell Error

Device Unauthorized / Offline

USB debugging prompt not appearing or device not recognized by ADB.

Run: adb kill-server && adb start-server
Revoke & re-enable USB Debugging on phone.
C Compilation

Segmentation Fault (Core Dumped)

Occurs when accessing invalid memory addresses or uninitialized pointers.

Debug with GDB: gcc -g main.c && gdb ./a.out
Type run then backtrace.
